# Graphline demo design

Concept: a guided technical walkthrough, following one customer case from message to graph decision, human ticket and remembered context.

Palette comes from the working application's CSS: blue #1f63ef, ink #162137, light canvas #f5f7fb, muted #737e90. The actual application recording is the focal element. A thin top anchor names the current task; the bottom rail carries the explanation and chapter progress. No decorative mock interface.

Use locally embedded Manrope for labels and clean system sans for captions if no bundled body font is available. Source code and query evidence use an embedded monospace font. Source footage remains continuously visible. Camera framing moves toward the live input and then the graph result. Comfortable holds follow each operation. All data and counts visible in footage come from the running application and FalkorDB.
