## Description

Graphline by ANTIINTERNS uses FalkorDB to connect customer conversations, intent keywords, approved policies, team routing and support tickets.

This full local walkthrough shows real application interactions: searching the inbox, a graph-policy reply, refund and human-support ticket creation, customer memory across conversations, browser reload, and read-only Cypher query results from the same synthetic demonstration graph.

The video is a continuous browser recording with motion reframing, captions and locally synthesized narration. The query presenter is a labeled recording aid. All demonstration data is synthetic.

Current scope: the standalone prototype does not connect to WhatsApp or send external messages. Optional OpenRouter drafting is implemented but is not exercised in this recording. The default response comes from graph policy. Human handoffs create assigned tickets; no completed employee response is simulated.
